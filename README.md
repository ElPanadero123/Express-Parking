# Express Parking

¡Bienvenido a **Express Parking**! 🚗

**Express Parking** es una aplicación desarrollada en Flutter diseñada para facilitar la búsqueda y gestión de estacionamientos. Esta aplicación permite a los usuarios encontrar estacionamientos disponibles, hacer reservas, y gestionar sus pagos de forma rápida y sencilla.

## Características

- 🔍 **Búsqueda de Estacionamientos:** Encuentra estacionamientos disponibles en tiempo real.
- 📅 **Reservas:** Realiza reservas para asegurarte un lugar en el estacionamiento deseado.
- 💳 **Gestión de Pagos:** Paga por tu estacionamiento directamente desde la aplicación.
- 🗺️ **Mapa Interactivo:** Visualiza la ubicación de los estacionamientos en un mapa interactivo.
- 🔔 **Notificaciones:** Recibe recordatorios y notificaciones importantes sobre tus reservas.

## Instalación

Sigue estos pasos para instalar y ejecutar **Express Parking** en tu entorno local:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/express-parking.git
   ```
2. **Navegar al directorio del proyecto:**
   ```bash
   cd express-parking
   ```
3. **Instalar las dependencias:**
   ```bash
   flutter pub get
   ```
4. **Ejecutar la aplicación:**
   ```bash
   flutter run
   ```

## Tecnologías Utilizadas

- **Flutter:** Framework para el desarrollo de aplicaciones móviles.
- **Dart:** Lenguaje de programación utilizado por Flutter.
- **Firebase:** Utilizado para la autenticación y base de datos en tiempo real.
- **Google Maps API:** Para la integración del mapa interactivo.
